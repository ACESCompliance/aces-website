# ACES Compliance Systems — Website

Marketing website for ACES Compliance Systems LLC — "Buying your time back" (v2, Oct 2026).

- **Live:** https://acescompliancesystems.com
- **Stack:** Single static HTML page, hosted on Netlify
- **Form:** Submits to Supabase `website_consultation_requests` (source = `website_timeback_form`)
- **Deploy:** run "Push Website.bat" in the parent folder — Netlify auto-deploys from `main`

## Files

- `index.html` — the one-page site (hero, problem, Sprint, offer, fit, about, FAQ, contact)
- `logo.png` — brand logo
- `archive/` — v1 OSHA-era site (not linked, blocked in robots.txt)
